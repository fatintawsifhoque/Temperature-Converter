
# ️ Temperature Converter

A real-time, bi-directional Temperature Converter built with **React** and **Tailwind CSS**. 

This project focuses on clean state management and event handling, avoiding common pitfalls like infinite re-renders in React.

---

### ✨ Features

- **Bi-Directional Sync:** Instant conversion between Celsius and Fahrenheit as the user types.
- **Event-Driven Architecture:** Uses direct `onChange` handlers instead of `useEffect` to prevent unnecessary re-renders and infinite loops.
- **Edge Case Handling:** Properly manages empty states and zero values using `parseFloat` and `isNaN` checks.
- **Clean UI:** Features a minimal, centered design with Lucide icons and smooth focus states.

---

### 🛠️ Tech Stack

- ⚛️ **React** (Functional Components & `useState` Hook)
- 🎨 **Tailwind CSS** (Utility-first styling)
-  **lucide-react** (For crisp, scalable icons)
